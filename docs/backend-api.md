# Backend API - Herramientas útiles

## Axios
Axios es una librería de JavaScript para realizar peticiones HTTP a servidores. Se utiliza como alternativa a fetch() y facilita el envío de datos, manejo de errores y configuración de peticiones.

## Postman
Postman es una herramienta para probar APIs. Permite enviar peticiones GET, POST, PATCH y DELETE sin necesidad de usar el frontend. Es muy útil para comprobar si el backend funciona correctamente.

## Sentry
Sentry es una plataforma de monitorización de errores. Se utiliza para detectar fallos en aplicaciones en tiempo real y registrar errores del frontend o backend.

## Swagger
Swagger es una herramienta para documentar APIs REST. Permite visualizar endpoints, probar rutas y generar documentación profesional para desarrolladores.
